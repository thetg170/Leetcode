Given a grid of elevations, find the cells that can send water to both oceans. Water moves across a shared edge to a cell at most as high. The Pacific touches the top and left edges, and the Atlantic touches the bottom and right edges. Return zero-based [row, column] pairs in any order.

## Example

```text
heights = [[1,2],[2,3]] → [[0,1],[1,0],[1,1]]
```
