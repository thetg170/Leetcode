Reconstruct the binary tree described by its preorder sequence (root, left, right) and inorder sequence (left, root, right). The values are unique and the traversals come from the same valid tree. Return its root.

## Example

```text
preorder = [8, 3, 6, 12], inorder = [3, 6, 8, 12] → [8, 3, 12, null, 6] (level order)
```
