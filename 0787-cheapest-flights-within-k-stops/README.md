Flights are directed triples [origin, destination, price] between airports numbered from 0 through n - 1. Find the minimum total price from src to dst using at most k intermediate airports. Return -1 if no eligible itinerary exists.

## Example

```text
n = 4, flights = [[0,1,4],[1,2,4],[2,3,4],[0,3,20]], src = 0, dst = 3, k = 1 → 20
```
