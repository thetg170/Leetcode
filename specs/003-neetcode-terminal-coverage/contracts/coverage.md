# Terminal coverage contract

Run `lc review <numbered-directory>` as printed on each card. EN and VI for
new entries are available locally. Existing entries keep their current
statement and test coverage. The 107 new starters provide interfaces and
examples for practice. `lc test` requires a curated case file for the selected
problem and reports an unavailable suite clearly.

Use published problem slugs for identification and the exact repository path
for commands. The Anki deck still contains 150 notes and 150 cards after updating
front fields. A card without a curated local suite is tagged `needs-local-tests`.
