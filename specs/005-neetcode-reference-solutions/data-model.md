# Data model

- **Starter path** — `files.reference` as used by the draft generator today.
- **Optional archived path** — `files.archived_solution` is a file inside the
  problem directory. The 107 new entries use `reference.py`.
- **Legacy archived path** — when the optional field is absent, the CLI
  continues to return the previous non-starter reference file.
- **Provenance** — per-file attribution and a shared upstream MIT notice.
