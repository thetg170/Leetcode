# Quickstart

1. Chạy `lc review 0226-invert-binary-tree` và sửa một dòng trong bản nháp.
2. Nhấn `Esc`, sau đó `Space l s` để xem lời giải Python local.
3. Nhấn `q` để quay về đúng bản nháp và vị trí con trỏ.
4. Chạy `lc reference 0226-invert-binary-tree` để xác nhận file tham khảo.
5. Chạy một lượt review mới để xác nhận nháp vẫn được tạo từ khung Python.
