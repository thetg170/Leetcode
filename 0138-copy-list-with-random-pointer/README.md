Deep-copy a linked list whose nodes have val, next, and random fields. A random pointer may refer to any node in the list or be null. Preserve every connection using only newly allocated nodes in the copy. An empty input produces an empty copy.

## Example

```text
[(4, 1), (8, 0)] as (value, random index) → [(4, 1), (8, 0)] with distinct node objects
```
