# Phím tắt LeetCode

Nhấn `Esc` về Normal mode trước khi dùng phím trong Neovim.
Với `Space l t`, bấm lần lượt Space, l, t.

| Việc cần làm | Phím hoặc lệnh |
| --- | --- |
| Mở bảng phím | `Space l h` |
| Xem lời giải tham khảo | `Space l s` |
| Đóng bảng hoặc lời giải | `q` hoặc `Esc` |
| Lưu file hiện tại | `:w` rồi Enter |
| Lưu tất cả buffer đã sửa | `:wall` rồi Enter |
| Lưu và chạy test | `Space l t` |
| Lưu và chạy ví dụ | `Space l r` |
| Đóng kết quả test | `q` trong cửa sổ kết quả |
| Đổi đề EN/VI | `Space l l` |
| Chọn bài khác | `Space l p` |
| Mở bài kế tiếp | `Space l n` |

Cả 150 bài NeetCode 150 đều có lời giải tham khảo. Nếu một bài ngoài bộ này
chưa có lời giải local, xem mặt sau thẻ Anki hoặc liên kết LeetCode trong đề.
Cả 150 bài NeetCode 150 có test local. Run cần ví dụ riêng của bài đang mở.

## Rời phiên tmux

| Việc cần làm | Phím hoặc lệnh |
| --- | --- |
| Chuyển pane trái/phải | `Ctrl+Space` rồi `h` / `l` |
| Chuyển pane dưới/trên | `Ctrl+Space` rồi `j` / `k` |
| Chỉnh độ rộng pane | `Ctrl+Space` rồi `H` / `L` |
| Phóng to pane hoặc thu lại | `Ctrl+Space` rồi `z` |
| Rời phiên và giữ workspace | `Ctrl+Space` rồi `d` |
| Quay lại phiên đang làm | `lc resume` trong terminal |

Để đóng hẳn, ở editor bên phải dùng `:wall` rồi `:qa`. Ở pane đề còn lại,
dùng `:q`. Dùng `lc review <bài>` khi bạn muốn bắt đầu một bản nháp mới.
