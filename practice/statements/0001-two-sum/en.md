Find two different positions in the integer list `nums` whose values add up to
`target`. Return the two zero-based indices in either order. Each valid input
has exactly one pair.

## Example

```text
nums = [8, 4, -1, 10], target = 3
indices = [1, 2]   (4 + (-1) = 3)
```

## Constraints

- `2 <= len(nums) <= 10,000`.
- Each value and `target` is between `-10^9` and `10^9`.
- Use two distinct indices even when the values at those indices are equal.
