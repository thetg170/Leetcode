A signal starts at vertex k in a directed network with vertices 1 through n. Each triple [u, v, w] gives the travel time w from u to v. Return the earliest time by which all vertices can receive the signal, or -1 if any vertex is unreachable.

## Example

```text
times = [[1,2,3],[1,3,9],[2,3,2]], n = 3, k = 1 → 5
```
