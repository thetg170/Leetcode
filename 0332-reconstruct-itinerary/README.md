Each ticket is a directed flight [departure, arrival]. Starting at JFK, use every ticket exactly once and return the airport sequence. A valid route exists. Choose the lexicographically smallest sequence when more than one route is possible.

## Example

```text
tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","JFK"],["ATL","JFK"]] → ["JFK","ATL","JFK","SFO","JFK"]
```
