Return the distinct requested words traceable on the lowercase letter grid. Consecutive letters must occupy cells touching horizontally or vertically, and an individual trace cannot reuse a cell. Any result order is allowed.

## Example

```text
board = [['q', 'a'], ['r', 't']], words = ['qa', 'qat', 'qar', 'trq'] → ['qa', 'qat', 'trq']
```
